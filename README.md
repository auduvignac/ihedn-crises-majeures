# ihedn-template-rapport
Template relatif à la rédaction d'un rapport de comité IHEDN

## À lire avant toute contribution

Les consignes éditoriales et méthodologiques du projet sont centralisées dans
[`AGENTS.md`](AGENTS.md) et dans les notes du dossier
[`notes_contextuelles/`](notes_contextuelles/). Avant toute modification du
rapport, lire en priorité le guide de rédaction, le plan du rapport et la
*checklist* de relecture afin de préserver le ton institutionnel, la structure
LaTeX et la ligne doctrinale du document.
