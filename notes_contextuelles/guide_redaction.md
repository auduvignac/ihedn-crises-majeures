# Guide rédactionnel

## Objet du document

Ce document constitue la référence rédactionnelle du projet.

Toute modification apportée au rapport doit respecter les règles de structure, de style, d'argumentation et de présentation décrites ci-dessous.

En cas de conflit entre une proposition de rédaction et ce guide, le présent guide prévaut.

---

# Instructions pour les agents IA

Lors d'une modification :

1. Lire intégralement la ou les sections concernées avant toute réécriture importante.
2. Préserver le ton institutionnel du rapport.
3. Ne jamais inventer de source.
4. Ne jamais inventer de référence bibliographique.
5. Ne jamais inventer de citation.
6. Ne pas modifier la structure générale du rapport sans justification explicite.
7. Préférer des modifications localisées plutôt que des réécritures massives.
8. Maintenir la cohérence avec les sections précédentes et suivantes.
9. Vérifier la cohérence des références croisées.
10. Vérifier la compilation LaTeX après modification.
11. Conserver les commandes LaTeX existantes sauf nécessité démontrée.
12. Préserver les labels, références, figures, tableaux et annexes.

# Principes spécifiques au rapport « Crises majeures »

Le rapport considère que :

* les associations IHEDN ne se substituent jamais aux autorités publiques ;
* la gestion opérationnelle des crises relève des autorités compétentes ;
* la plus-value des associations IHEDN réside principalement dans la préparation, l'accompagnement et l'analyse des crises ;
* le questionnaire constitue un outil de cartographie et d'objectivation des compétences ;
* les recommandations doivent demeurer réalistes, applicables et compatibles avec les dispositifs existants ;
* les analyses doivent distinguer systématiquement les périodes d'avant-crise, de crise et d'après-crise ;
* les propositions doivent s'inscrire dans une logique de complémentarité avec les acteurs institutionnels.

# Principes de rédaction

Le rapport doit :

* répondre à une problématique clairement formulée ;
* privilégier l'analyse plutôt que la description ;
* distinguer constats, analyses et recommandations ;
* s'appuyer sur des sources identifiées ;
* éviter les affirmations non démontrées ;
* conserver un ton institutionnel et neutre.

Le rapport n'est ni un article de presse, ni une tribune d'opinion.

---

# Utilisation des sources

Toute affirmation factuelle doit être :

* sourcée ;
* vérifiable ;
* référencée dans la bibliographie.

Ordre de priorité des sources :

1. Sources institutionnelles ;
2. Rapports publics ;
3. Publications académiques ;
4. Ouvrages spécialisés ;
5. Presse spécialisée ;
6. Presse généraliste.

Les arguments d'autorité doivent être évités.

Chaque affirmation importante doit pouvoir répondre à la question :

> Comment savons-nous ce qui est affirmé ?

---

# Formulations à privilégier

Utiliser préférentiellement :

* « dans cette perspective »
* « il convient de distinguer »
* « cette démarche vise à »
* « les travaux mettent en évidence »
* « plusieurs enseignements peuvent être tirés »
* « cette analyse conduit à »
* « au regard des éléments étudiés »
* « il apparaît que »
* « les éléments recueillis suggèrent que »

---

# Formulations à éviter

Éviter :

* « il est évident que »
* « il est certain que »
* « sans aucun doute »
* « il faut absolument »
* « révolutionnaire »
* « exceptionnel »
* « indispensable »
* « majeur » sans justification explicite

Privilégier des formulations nuancées et démontrées.

---

# Rédaction des recommandations

Les recommandations doivent :

* répondre directement à la problématique ;
* être réalistes ;
* être argumentées ;
* identifier un acteur responsable ;
* être formulées sous forme d'action.

Exemple :

❌ Renforcer la résilience nationale.

✔ Développer un programme annuel de sensibilisation des élus locaux aux dispositifs PCS.

Les conclusions doivent systématiquement déboucher sur des propositions concrètes à destination des décideurs.

---

# Structure du rapport

Le rapport doit comporter :

1. Page de couverture
2. Sommaire
3. Résumé exécutif
4. Mots-clés
5. Introduction
6. Développement
7. Conclusion et recommandations
8. Bibliographie
9. Annexes

## Introduction

L'introduction doit :

* contextualiser le sujet ;
* définir les notions importantes ;
* présenter l'intérêt du sujet ;
* formuler la problématique ;
* annoncer le plan.

## Développement

Le développement constitue la démonstration répondant à la problématique.

Le plan doit généralement comporter :

* deux ou trois parties ;
* des sous-parties numérotées.

Chaque partie doit :

* commencer par une courte introduction ;
* se terminer par une courte conclusion ;
* s'articuler logiquement avec les parties voisines.

Les paragraphes doivent progresser :

* du simple vers le complexe ;
* du connu vers le plus novateur ;
* du constat vers la proposition.

## Conclusion

La conclusion doit :

* répondre explicitement à la problématique ;
* synthétiser les enseignements ;
* ouvrir des perspectives ;
* formuler des recommandations.

## Annexes

Les annexes doivent :

* être numérotées ;
* être appelées dans le texte ;
* apporter une réelle valeur ajoutée au lecteur.

---

# Style

Le style doit être :

* clair ;
* précis ;
* fluide ;
* concis ;
* neutre.

Éviter :

* les polémiques ;
* les effets de style ;
* l'humour ;
* les formulations excessives ;
* les répétitions inutiles.

---

# Bibliographie

La bibliographie doit recenser l'ensemble des sources effectivement utilisées.
